# Расписание ММФ

Мини-приложение для расписания занятий дневного отделения механико-математического факультета БГУ. Данные берутся напрямую с [mmf.bsu.by](https://mmf.bsu.by/ru/raspisanie-zanyatij/dnevnoe-otdelenie/) и раскладываются в удобный список по дням.

## Что умеет

- Выбор курса (1–4) и группы в настройках; список групп подтягивается с сайта, поэтому он всегда актуален (на 3 курсе, например, нет 10 группы, зато есть 11 и ВФ).
- **Мои подгруппы** — выбор отдельный для каждого предмета, потому что деление на разных парах разное: на роботах ты «Б», на китайском «а», а биомеханику можно отметить как «не моё» и убрать совсем.
- Автоматическое определение 1-й и 2-й недели по минскому времени, плюс режим «все недели», чтобы заранее посмотреть пары другой недели.
- Пары с ограничением по датам («с 29.09», «до 18.11», разовый информационный час 01.09) показываются только в те дни, когда они действительно есть.
- Подсветка сегодняшнего и завтрашнего дня, чип «сейчас» у текущей пары, автоскролл к сегодня при открытии.
- Тёмная тема по умолчанию и переключатель на светлую в настройках; выбранная тема применяется до первой отрисовки, без вспышки другого фона.
- Адаптивная вёрстка без горизонтального скролла: одна колонка на телефоне, две на планшете, три на широком экране; настройки открываются снизу на телефоне и по центру на десктопе. Можно поставить на домашний экран телефона (PWA-манифест).
- Все настройки (курс, группа, подгруппы, недели, тема) хранятся в `localStorage` — без базы данных и аккаунтов.
- Последнее загруженное расписание сохраняется локально, поэтому приложение открывается, даже если сайт факультета недоступен.

## Локальный запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000.

Тесты парсера (работают на сохранённых HTML-страницах из `tests/fixtures`):

```bash
npm test
```

## Начало семестра

Номер недели считается от понедельника первой недели семестра. Константа одна:

```ts
// lib/week.ts
export const SEMESTER_START = "2026-08-31";
```

В начале каждого семестра достаточно поменять эту дату.

## Публикация на Vercel

1. Залить проект в git-репозиторий.
2. На vercel.com выбрать Add New → Project и импортировать репозиторий.
3. Framework Preset определится как Next.js, переменные окружения не нужны.
4. Deploy.

Страницы расписания и список групп кэшируются на 30 минут (ISR), так что сайт факультета не получает лишних запросов.

## Структура

- `app/page.tsx` — экран расписания
- `app/api/schedule`, `app/api/catalog` — серверная загрузка и парсинг страниц ММФ
- `lib/parseSchedule.ts`, `lib/parseCatalog.ts` — разбор HTML в структуры данных
- `lib/week.ts` — минское время и нумерация недель
- `lib/filterLessons.ts` — фильтры по неделе, датам и подгруппам
- `components/` — список дней, карточка пары, экран настроек
